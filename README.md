NEON VICE is an offline web app that turns a photo and a caption into a GTA-6-style poster cover: an angled multi-panel "Dusk Collage" layout, a cinematic sunset/neon grade, and bundled Anton display type. It exports finished covers as PNG at 1080×1080, 1080×1350 and 1920×1080. Photos never leave the machine.

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080
node main.ts    # writes the submission dossier to /output
```
